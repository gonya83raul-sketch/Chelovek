# Передача работы в Claude Code (состояние на 26.10.2026, сайт app14)

Этот файл — самое короткое и полное описание того, как продолжить работу над атласом «Кто мы? — от молекулы до мысли» в Claude Code.
Подробная история решений — в NOTES.md (читать по нужде, он длинный).

## 1. Что это и где лежит
- Сайт: https://gonya83raul-sketch.github.io/Chelovek/ — ветка `main` репозитория `gonya83raul-sketch/Chelovek` (только собранный сайт).
- Исходники: ветка `source` того же репозитория. Адрес репозитория сменился: `git remote set-url origin https://github.com/gonya83raul-sketch/Chelovek.git`.
- Всё на three.js, без фреймворков. Два языка: RU (основной, пишем по-русски) и EN (собирается автоматически по словарю).
- Сейчас 72 сцены в четырёх разделах: Биохимия, Клетка, Тело, Мозг.

## 2. Пожелания пользователя (важно)
- Общаться по-русски. Работать самостоятельно, без лишних подтверждений: сделал → проверил → опубликовал → коротко отчитался.
- Каждую новую тему и крупную правку проверяют **рецензенты** (отдельные агенты-критики, см. п. 7), замечания исправляются до публикации.
- Всегда оба языка: после правок — перевод новых строк, в EN не должно оставаться русского.
- Публиковать после каждой готовой партии (APP+1).
- Не удалять раздел «Условности» в заметках сцен, подпись авторов 3D-моделей и кнопку «Поддержать».
- Сейчас идём по атласу Неттера (8-е изд.) по разделам с начала: «чего нет у нас — добавляем по парочке тем; что у Неттера лучше — исправляем у нас; с рецензорами».

## 3. Первый запуск на новой машине
```sh
git clone https://github.com/gonya83raul-sketch/Chelovek.git chelovek-src
cd chelovek-src && git checkout source
sh tools/setup.sh                     # модели из ветки main, three.js для тестов, pillow+playwright
python3 -m playwright install chromium   # если браузер для playwright ещё не стоит
python3 tools/build.py                # сборка → out/ и lt/
cd lt && python3 -m http.server 8765  # локальный сервер (оставить работать в отдельном окне)
```
Нужны: git, Python 3.10+ (pip: playwright, pillow, numpy), Node 18+ (npm). На Windows удобнее всего WSL или Git Bash.
Проверка: открыть http://127.0.0.1:8765/index.html#referred — должна открыться сцена «Отражённая боль».

## 4. Устройство исходников
- `src_page.html` — оболочка сайта, общие помощники и все «старые» сцены (makeSkeleton, makeVessels, makeHeart, makeBlood, makeSkin, makeImmune, makeEndo, makeSpinal, makeNeuron и т. д.). Большой файл — искать функции через grep.
- `bio/*.js` — сцены биохимии, `body/*.js` — новые сцены раздела «Тело». Первая строка файла — заголовок:
  `// @scene id makeFn | Название | Группа` (биохимия) или `// @scene id makeFn | Название | @body Группа` (тело; `@body ^Группа` — поставить группу в начало раздела).
- `tools/build.py` собирает всё; константа `APP = 'app14'` — имя папки версии, **увеличивать при каждой публикации**.
- `data/i18n/en/*.json` — словарь перевода «русская строка → английская». Последний файл — `b23_netter.json`, следующий делать `b24_*.json`.
- `data/mols.json`, `tools/mols.py` — молекулы (SMILES в LIB, своя генерация 3D; RDKit не нужен): `python3 tools/mols.py data/mols.json <ids>` → `python3 tools/mkdata.py`.
- `review/*.md` — отчёты рецензентов (последние: new-referred.md, netter-fixes-2.md, netter-intro-existing.md).
- `drafts/13_skull.js` — черновик следующей сцены «Череп» (в сборку не входит, см. п. 9).

## 5. Как устроена сцена (шаблон)
Функция `makeX()` возвращает объект:
`{ mobZoom?, scene, camera, controls, update(dt), ui(el), onKey(e), stats(), labels, drawScope(ctx,w,h) | null, accent, kicker, title, lede, notes }`.
- Режимы: `st.mode`, `setMode(m)`, перелёт камеры `st.fly = flyTarget(target, pos)` + `flyStep(st, camera, controls, dt)` в update.
- Мобильная камера: `const VIEWM = {...}, mqm = window.matchMedia('(max-width:700px)'), VV = (m) => (mqm.matches && VIEWM[m]) || VIEW[m];`
- Подписи: `{ text, pos: V3, color, show: () => bool }`; подвижная подпись — `pos` как функция, затем в update копировать (образец в bio/85_pituitary.js).
- UI-помощники: `seg`, `toggle`, `button`, `group`, `infoBox`, `h`; клик по объектам — `pickOn(() => self, camera, meshes, cb)` (у меша `userData.pick`).
- 3D-помощники: `organMat`, `glassMat(col,{keep:true})`, `ell3`, `blobGeo`, `tube`, `taperTube`, `glowNucleus`, `flowArrow`, `Sparks`, `bodyShell` (условное тело), `skelShell` + `loadSkeletonStatic` (настоящий скелет, body/10_planes.js), `SKEL_META` (суставы), `makeVessels` (сосуды скелета).
- Система координат скелета: 1 ед. ≈ 10 см, рост ≈ 17,1; **x > 0 — ЛЕВАЯ сторона человека**, z > 0 — вперёд; череп y 14.88–17.14.
- Кадр на десктопе 1440×900: снизу панель, слева сверху заголовок, справа сверху статистика. Видимая часть — верхние ~65% холста. Удобно: смещать цель камеры, чтобы объект был справа-сверху (см. `VW()` в body/12_referred.js).

## 6. Проверка
- `python3 tools/sweep.py $(cat tools/ids.txt)` — все сцены открываются без ошибок. Единственное допустимое предупреждение: `blood … toNonIndexed()`. Новую сцену добавить в tools/ids.txt (и в lt/ids.txt).
- Снимки: `python3 tools/snap.py <id> [size:390x844] [lang:en] adv:3 shot:a key:2 adv:2 shot:b` → `lt/a.png`, `lt/b.png`; смотреть их глазами (Read).
  Клик по кнопке: `"js:[...document.querySelectorAll('button')].find(b=>b.textContent.trim()==='Пульс').click()"`; камера: `"js:(()=>{const c=window.__cur();c.camera.position.set(x,y,z);c.controls.target.set(x,y,z);c.controls.update()})()"`.
  `adv:` не перерисовывает осциллограф и статистику — для них `sleep:2`. Скелету перед действиями нужен `sleep:6` (модель грузится).
- Всегда смотреть десктоп 1440×900, телефон 390×844 и пару снимков EN.

## 7. Рецензенты (как просит пользователь)
Запускать 1–2 фоновых агента (тип general-purpose) с заданием: «Ты строгий рецензент (анатомия/биохимия + подача). Ничего не правь, только отчёт. Сцена `<id>`, исходник `<файл>`, эталон — Неттер, стр. PDF N–M (рендер `pdftoppm -f N -l N -r 80 -png <pdf> /tmp/x`). Снимки через `tools/snap.py` с префиксом `crit_` в имени. Проверь: точность, тексты, кадрирование (заголовок/панель/статистика), подписи, телефон 390×844, EN, баги. Отчёт — `review/<имя>.md`, таблица `№ | серьёзность | где | проблема | конкретное исправление`.» После отчёта — исправить всё высокое и среднее.

## 8. Перевод и публикация
1. `python3 tools/build.py` пишет `out/_merged_en.mjs.missing.json` — список непереведённых строк. Перевести, добавить в `data/i18n/en/b24_*.json` (ключ — русская строка целиком, включая HTML), пересобрать до «строк без перевода 0».
   Однобуквенные строки (например `' ч'`) не переводятся вовсе — такие единицы писать нейтрально (`':00'`, `'%'`).
   В EN использовать кавычки “ ”, не «ёлочки».
2. Поднять `APP` в tools/build.py, собрать, прогнать sweep.
3. Сайт: клон ветки main рядом (`git clone -b main https://github.com/gonya83raul-sketch/Chelovek.git ../chelovek-site`), затем
   `cd ../chelovek-site && git pull --rebase && git rm -rq app14 && cp -r ../chelovek-src/out/site/. . && git add -A && git commit -m "app15: …" && git push`.
4. Исходники: `git add -A && git commit -m "…" && git pull --rebase origin source && git push origin HEAD:source`.
5. Дописать в NOTES.md раздел о сделанном.
