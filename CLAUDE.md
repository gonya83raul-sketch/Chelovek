# Проект «Кто мы? — от молекулы до мысли»
Интерактивный 3D-атлас человека (three.js). Пользователь пишет по-русски — отвечай по-русски.
**Начни с HANDOFF.md** — там установка, сборка, проверка, рецензенты, перевод, публикация и текущий план (атлас Неттера, раздел 2 «Голова и шея»). NOTES.md — подробная история, читать по нужде.
Эта ветка (`source`) — исходники; ветка `main` — только собранный сайт для GitHub Pages (https://gonya83raul-sketch.github.io/Chelovek/).
Работай самостоятельно, без лишних подтверждений; новые темы и крупные правки — через агентов-рецензентов; оба языка (RU+EN); после нескольких групп сцен — одна публикация (APP+1 в tools/build.py); не публиковать после каждой группы.
