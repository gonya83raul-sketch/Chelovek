# Рецензия 3D-сцен — группа «body» (раздел «Тело»)

Файл кода: `/home/user/Chelovek/src_page.html` (номера строк — ветка `source` на момент рецензии).
Соглашение сцен органов: x > 0 — левая сторона человека, z > 0 — вперёд, y — вверх.

**Общий класс багов (встречается 4 раза).** Если сначала сделать `ell3(..., p)`, то есть сдвинуть геометрию в точку `p`, а потом повернуть или отмасштабировать её саму либо меш (`geometry.rotateZ`, `mesh.rotation`, `mesh.scale`), то поворот и масштаб считаются вокруг начала координат мира, а не вокруг центра органа. Из-за этого орган уезжает со своего места или «прыгает» при пульсации. Правильно так: `ell3(rx, ry, rz)` без `p`, затем `rotate…`, затем `translate(p)`. Для пульсирующих мешей другой порядок: геометрия строится в нуле, а место задаётся через `mesh.position.copy(p)`.
