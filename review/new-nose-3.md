Исправление: (а) на ПК поднять камеру ниже, чтобы показать нос «снизу-сбоку»: `VSEL.ext` позиция `V3(-17.6, 1.8, 16.4)` → `V3(-15.5, -3.5, 17.5)` (цель `V3(-5.9, 0.4, 4.8)` не менять); (б) добавить тёмный эллипс-ноздрю на подошву целого носа: после строки 148 — `{ const nm = new THREE.Mesh(new THREE.CircleGeometry(0.42, 20), slitM); nm.scale.set(0.7, 1, 1); nm.rotation.x = Math.PI / 2; nm.position.set(-0.75, -2.62, 6.25); C1.add(nm); }` (он скрывается вместе с C1 только при `EX`-логике: добавить `nm` в `noseL`-ветку условия на строке 245, т. е. `c === noseL || c === nm` — либо сделать `nm` дочерним `noseL`: `noseL.add(nm)`, это проще и не требует правки update).
