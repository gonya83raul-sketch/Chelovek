## types — 3,5/5 (4,0–4,5 с правками)
Компьютер: «Все» в порядке. **В фокусе на клетке (кнопки «Мульти»…«Веретено») соседние формы остаются и лежат на счётчиках справа сверху; «Пуркинье»: дерево упирается в верхнюю кромку (подпись «дендритное дерево…» на y=8 кромки карточки). «Сеть» на телефоне: кожа слева и мышечные волокна справа обрезаны кромками.**
1. **(высокая, комп. и телефон; проверено)** `  function go(id) { st.view = id; st.fly = 1; st.next = st.t + 1.2; pulses = []; }` → `  function go(id) { st.view = id; st.fly = 1; st.next = st.t + 1.2; pulses = []; cells.slice(0, 7).forEach((c) => { c.g.visible = id === 'all' || id === 'net' || c.def.id === id; }); }` (в фокусе остаётся только выбранная клетка — счётчики и заголовок свободны; «Все» и «Сеть» не тронуты).

## Не внесено
- synapse: окраска пузырьков цветом медиатора (r5e п. 3) — на копии пробовал `lerp(…, 0.7)` к белому: у глутамата почти не отличается от серого, не рекомендую без более насыщенной формулы; кадр на 8 % дальше (п. 4), NMDA-пробка (п. 5).
- stem: «ядра черепных нервов» `left: true` (r5b п. 3), миелин/оболочка гладкая (п. 5); линии волокон на телефоне поверх цифр в режимах 3–4.
- types: миелин-бусины, псевдоуниполярный без Т-ветви (r5b п. 4).
- spinal: кожа пластиной (r5d п. 5); сегменты на компьютере — справа от колонки обрезок седалищного нерва у правой кромки.
