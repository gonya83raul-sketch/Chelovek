# Задание исправителю 3D-моделей атласа «Кто мы?»

Ты работаешь в СВОЕЙ рабочей копии репозитория (git worktree), путь и порт указаны в сообщении. Все команды запускай из неё, с переменной `LT_PORT=<твой порт>` для тестовых скриптов (иначе увидишь чужую сборку). Пользователь пишет по-русски; комментарии в коде — по-русски, в стиле окружающего кода (кратко).

Прочитай NOTES.md (раздел «Как собирать»). Коротко:
- сборка: `python3 tools/build.py` (ошибки синтаксиса печатает; lt/ — локальный тест);
- снимок сцены: `LT_PORT=<порт> python3 tools/lt.py <id> key:2 "window.__adv(3)" shot:имя` → lt/имя.png и lt/<id>.png (печатает ошибки страницы);
- снимки для рецензии всех режимов: `LT_PORT=<порт> python3 tools/revshots.py --out lt/rev2 <id>…` → lt/rev2/<id>_m1.jpg, _side, _close;
- нет ошибок во всех режимах: `LT_PORT=<порт> python3 tools/sweep.py <id>…`;
- телефон: `LT_PORT=<порт> python3 tools/mob.py <id>` → lt/m_<id>.png (запусти сервер сначала через lt.py).
- молекулы: SMILES в tools/mols.py (LIB), генерация `python3 tools/mols.py data/mols.json <ids>` (собственный генератор tools/molgen.py; при необходимости можно `pip install rdkit` и строить конформер RDKit), затем `python3 tools/mkdata.py` (перегенерирует bio/00_data_*.js).

## Что делать
1. Прочитай отчёт критика (путь в сообщении) — это список дефектов с местом в коде и предложением. Отчёт — мнение, а не приказ: проверь каждое утверждение по коду и снимкам; ошибочное — пропусти и отметь почему.
2. Исправь дефекты, начиная с высокой серьёзности. Цель — заметно лучше и научно верно; правки кода разумного объёма (процедурная геометрия, материалы, камера, подписи, данные молекул). Готовые модели models/*.txt не трогай.
3. Меняй только сцены своей группы (их функции/файлы). Общие помощники (функции вне makeXxx в src_page.html, bio/01_biokit.js) — только если это прямо указано в сообщении как твоя зона; иначе обходись локальными правками в сцене.
4. После каждой сцены: сборка, снимки всех режимов, посмотри их сам (Read открывает картинки) и сравни с lt/rev/<id>_*.jpg «до». Проверь, что нет ошибок (`sweep.py`), что на телефоне не сломалось.
5. Не меняй тексты сцен без нужды (они будут переводиться); если меняешь форму — поправь подписи/пояснения, если они стали неверны.
6. Коммить в свою ветку по мере работы (`git add -A; git commit -m "..."` — сообщения по-русски, в конце строки
   `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` и `Claude-Session: https://claude.ai/code/session_01CAsbEKYKPKpphinWsqDRBa`). НЕ пушь, НЕ трогай ветки source/main, не публикуй.
7. Сгенерированные файлы bio/00_data_mol.js и bio/00_data_pdb.js можно коммитить — при слиянии я их перегенерирую.
